# 도티두잇 홈페이지

도티두잇을 소개하고 사용 방법을 안내하는 공식 홈페이지 작업 공간입니다.

원격 저장소: `git@github.com:kizwond/doti_doit_web.git` · 기본 브랜치: `main`

## 현재 준비된 내용

2026-10-28 홈페이지 목차와 소개 원고를 작성했습니다. 주요 페이지 7개, 사용 가이드 3개, 페이지별 검색 제목과 설명이 준비되어 있습니다. 모든 원고는 초안이며, 아직 홈페이지 화면 구현이나 공개 배포는 하지 않았습니다.

## 구조

- `content/pages/`: 홈·브랜드 이야기·미션·루틴·기록·FAQ·설치 안내 원고
- `content/guides/`: 첫 미션·걷기 기록·운동 루틴 사용 가이드
- `docs/`: 홈페이지 구성과 편집 근거
- `src/`: 앞으로 구현할 홈페이지 소스
- `public/`: 앞으로 홈페이지에 사용할 공개 이미지와 정적 파일

## 원고와 구현 기준

원고의 `route`는 앞으로 구현할 주소입니다. 현재 실행 가능한 웹페이지는 아닙니다. `status: draft`인 문서는 사이트를 구현할 때 공개 결과물에서 제외하도록 처리해야 합니다.

기능 설명은 Android Preview 331을 기준으로 확인했습니다. 공개 설치본의 기능과 실제 화면이 원고와 일치하는지 확인해 반영합니다. 대표님 의도를 추정한 브랜드 이야기는 창업 일화나 실제 인용문으로 표현하지 않았습니다.

다음 작업은 원고를 바탕으로 홈과 주요 안내 페이지의 모바일 화면을 구현하는 것입니다. 프레임워크·도메인·호스팅과 실제 스토어 연결 주소는 아직 설정하지 않았습니다.
