# 도티두잇 홈페이지

도티두잇을 소개하고 사용 방법을 안내하는 공식 홈페이지 작업 공간입니다.

## 구조

- `src/`: 홈페이지 소스
- `public/`: 홈페이지에 공개할 이미지와 정적 파일
- `docs/`: 홈페이지 구성과 작업 기록

현재는 작업 폴더와 Git만 준비한 상태입니다. 프레임워크·디자인·도메인·호스팅은 홈페이지 작업을 시작할 때 정합니다.

## 원격 저장소 연결

GitHub 저장소 이름은 `doti_doit_web`, 공개 범위는 Private를 권장합니다.
로컬에 초기 커밋이 있으므로 GitHub에서는 README·.gitignore·라이선스 없이 빈 저장소로 만들면 바로 연결할 수 있습니다.
원격 저장소 주소가 정해지면 `origin`을 등록하고 `main` 브랜치를 푸시합니다.

홈페이지 공개 여부와 소스 저장소 공개 여부는 별개입니다. 비공개 저장소에서 개발해도 완성한 홈페이지는 공개 배포할 수 있습니다.
