# 모티도티 홈페이지 로고 수정

- 기존 SVG는 잘린338×67 PNG를 포함한 래퍼였다. 모티도티98 앱/스토어와 같은 완전한366×84 벡터로 교체했다.
- 홈페이지 모티도티 소개 영역의 `img` 공통 CSS가 로고까지55×55로 강제하던 문제를 수정했다. 원래 HTML에서 의도한169px 너비와 원본 비율로 표시한다. 새싹 그림은55×55를 유지한다.
- 로고·스타일시트URL에 원본SVG 해시 기반 캐시 키를 적용해 기존 방문자에게도 새 자산을 불러오게 했다.7개 언어의 홈은 같은 템플릿을 사용한다.
- 원본은 `doti_moti/docs/brand/motidoti-wordmark.json`, 동기화는 같은 폴더의 `sync-web-wordmark.mjs`다. 생성/동기화 확인 절차를 원본 저장소에 문서화했다.
- 관련 브라우저2개 검사에서7개 언어 소개/탐색과320~1440px18개 조합, 로고 너비·비율·이미지 로딩을 확인했다. 공개 빌드91페이지/4086개 링크·자산 검사 통과. 문구·방침·통계 동의/기존 Analytics ID는 변경하지 않았다.

최종 공개 응답/실제 화면과 Actions 결과는 `docs/qa/2026-11-27-logo-surfaces`에 기록한다.
