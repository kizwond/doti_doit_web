# 도티두잇 홈페이지 원고의 근거와 해석

이 문서는 내부 편집 자료다. 공개용 원고는 `content/`에 있으며 모두 초안이다. 브랜드 이야기에는 대표님의 요청을 해석해 제안한 문장이 포함되어 있다. 대표님의 실제 발언이나 확정된 회사 철학으로 인용하지 않는다.

## 확인한 제품 내용

기준은 `doti_doit` 저장소 Android Preview 331, 제품 커밋 `a367f8c`와 인계 문서다. 스토어에 배포된 버전이 동일하다는 뜻은 아니다.

| 원고의 내용 | 확인 근거 |
| --- | --- |
| 걷기·근력 운동·달리기·부모님께 마음 전하기·단전호흡 미션 | `doti_doit/docs/handoffs/2026-10-28-preview-328-ceo-routines.md`, `PracticeMissionCatalog.kt` |
| 여러 활동·시간·반복으로 구성한 루틴, 연결 루틴 선택 | 같은 328 인계 및 `MissionResultChoiceSheet.kt` |
| 총 걸음수·스마트폰 미사용 시간 기준에서 자동기록 제공 | `doti_doit/docs/handoffs/2026-10-27-preview-319-automatic-criterion.md` |
| 하루 걸음과 운동 중 걸음의 구분, 사용시간이 수면 측정은 아니라는 제한 | `OfficialMissionGuidance.kt` |
| 날짜와 시각 기록별 피드 작성, 측정데이터와 루틴 상세 | `MissionAchievementHistory.kt` |
| 미션 없이 사진·메모 피드 작성, 사진과 카드 편집 | 앞선 사용자 요청 및 현재 `MissionFeedPresentation.kt`, `RecordSharing.kt` |
| 미션·루틴·피드 이미지 공유, Play 검색 안내 | `doti_doit/docs/handoffs/2026-10-28-preview-331-sharing-cleanup.md` |
| 권한 설명과 초기 동의 흐름 | `doti_doit/docs/handoffs/2026-10-27-preview-314-three-permissions.md` |

위 코드 경로의 파일명만 적은 항목은 `doti_doit/app/src/main/java/com/doti/doit/` 기준이다.

## 대표님 의도에 대한 제안

| 관찰한 요청 | 이번 원고에서 제안한 해석 |
| --- | --- |
| 운동 외에 부모님께 사랑한다 말하기 같은 기본 미션 포함 | 생활의 여러 영역에서 스스로 중요하게 생각한 일을 실천하도록 돕는다 |
| 목표 값과 측정 항목을 사용자가 조절 | 다른 사람의 기준보다 자신의 상황에 맞는 목표를 존중한다 |
| 준비·수행·마무리를 갖춘 실제적인 루틴 구성 요청 | 시작한 뒤 매번 다음 행동을 고민하는 수고를 줄인다 |
| 미션 설명을 담백하게 보여주고 과한 장식 제거 | 거창한 다짐보다 일상적인 이유를 편하게 담는다 |
| 미션 없는 피드와 사진·메모 중심 작성 요청 | 숫자로 표현되지 않는 하루의 느낌도 남길 자리를 둔다 |
| 기록 방식의 유기적인 연결과 불필요한 표시 축소 | 기록이 실천보다 더 큰 일이 되지 않도록 한다 |

이 해석은 브랜드 원고의 제안이며 창업 경위에 대한 사실 확인을 대신하지 않는다. 대표님 이름으로 된 인용문이나 ‘내가 이런 경험을 해서 만들었다’는 일화는 작성하지 않았다.

## 공개 내용에 넣지 않은 주장

사용자 수·만족도·전문가 추천·효과 수치, 특정 기간 내 습관 형성, 질병 개선이나 치료 효과, 모든 센서의 정확도, 모든 기기의 호환성, 무조건적인 자동기록, 개인정보가 절대로 외부로 나가지 않는다는 보장은 넣지 않았다. 요금·광고·백업·클라우드 정책도 Preview 설정만으로 확정하지 않았다.

## 실제 공개 때 확인할 정보

- 배포 채널과 화면: 공개 설치본에서 안내한 기능과 메뉴가 제공되는지 확인.
- 설치 연결: 검증된 Google Play 상세 주소를 사용. 회사 서버 Preview APK 주소는 일반 방문자 설치 버튼으로 사용하지 않음.
- iOS·도티모티: 개발 방향과 출시 사실을 구분. 출시일·스토어 링크를 추측하지 않음.
- 운영 정보: 실제 문의처, 개인정보처리방침·이용약관의 확정 주소, 운영자 표기.
- 원고: 대표님 의도를 해석한 브랜드 이야기의 표현 적합성. 현재 단계의 작성과 Git 저장을 막는 승인 절차는 아님.

## 작성 범위

2026-10-28 홈페이지 목차, 브랜드 방향, 주요 페이지 7개, 사용 가이드 3개를 작성했다. 외부 공개나 사이트 배포는 진행하지 않았다. 원고를 읽는 방식과 화면 구현은 별개이며, 이번 결과물은 홈페이지 제작에 사용할 콘텐츠 초안이다.
