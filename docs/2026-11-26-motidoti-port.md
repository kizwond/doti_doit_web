# 모티도티 공통 기능·이름 정비

모티두잇520을 이식한 모티도티의 현재 기능을7언어 소개에 맞췄다. 기존 주소는 유지한다.

- 기존 글자 모양과 색상 체계를 재사용해 Moti+Doti 순서의SVG 로고를 만들고 모티도티 영역에 사용했다. 새 비트맵 이미지를 생성하거나 로고 크기를 키우지 않았다.
- 공식미션37개, 언제까지→무엇을→몇번, 선택형 일단위 수행목표, 저장=수행, 입력 데이터·루틴 삭제·히스토리 표·지도/글/스티커 편집을 설명한다.
- 서버에 비공개 계정 보관·오프라인 재전송과 SNS 선택 게시를 구분하고, 기본값 갱신으로 기존 자료를 덮어쓰지 않는 점과 시즌 재판정/피드 스냅샷 보존을 안내한다.
- 회원가입이 없는 두잇과 회원 기반 모티를 혼동하지 않는다. 캠페인/기부 출시나 AWS 이전을 완료했다고 쓰지 않는다.
- 공개91페이지·7언어·320px/데스크톱·이미지/탐색·개인정보 링크·통계 동의/철회 등 기존 웹 검사19개 통과. 기존Analytics 설정과 URL/Play 링크는 유지한다.
