# 실제 앱 UI 입체 연출·설명 페이지 단순화 — 2026-11-27

## 사용자 최종 방향

레퍼런스의 구성과 입체감은 참고하되, 새로 만든 기기/유리 오브젝트가 모티두잇의 분위기와 다르다는 피드백을 반영한다. **실제 앱 UI가 3D 팝처럼 떠 보이는 연출**을 홈에 사용하고, 기능을 읽는 하위 페이지의 화면 예시는 평면으로 유지한다. 이 작업은 두 앱 소스를 원복하는 별도 요청과 분리된 홈페이지 수정이다.

## 안내 페이지 공통 정리

- 미션·루틴·기록과 피드, 사용 안내와 FAQ 등 공통 템플릿에 적용했다. 특정 한 화면만 보정하지 않았다.
- ‘이 페이지에서’의 외부/내부 배경, 왼쪽 테두리, 둥근 내부 박스를 없앴다. 제목과 이동 링크만 남긴다.
- 캡처를 감싸던 색 배경·안쪽 선·그림자·둥근 테두리를 없앴다. 실제 캡처 픽셀 안의 앱 입력창 테두리는 그대로다. 앱 화면을 홈페이지 장식과 혼동하지 않는다.
- 목차와 본문 제목을 같은 문자열로 표시하며 본문에만 남아 있던1/2/3 번호를 제거했다. 앵커 ID와 링크는 보존하고 ‘1회’·‘10,000보’ 같은 내용 숫자는 유지한다.
- 이미지가 있는 항목만 section이고 없는 항목은 옛 h2 규칙을 쓰던 혼합 구조가 중복 선의 원인이었다. 모든 h2 구획을 `guide-section`으로 통일하고 **인접 항목 사이 위쪽 선1개만** 사용한다. h2/마지막 항목 아래/다음 페이지 버튼 위에는 선을 추가하지 않는다. 문제였던 미션3~4 사이와5 아래도 같은 원칙을 따른다.
- 루틴과 걷기 설명에서 바로 반복되던 동일 캡처는 줄였다. 동영상 안내는 실제 구간 설정을 설명하는 위치에만 같은 화면을 쓰며 페이지당 캡처 개수를 채우려고 반복하지 않는다.

## 홈페이지의 실제 UI 입체 표현

- 이전 3D 기기/세라믹/유리 이미지의 **표시를 중단**했다. 기존 파일은 과거 화면과 출처 기록을 위해 보존하되 현재 HTML에서는 요청하지 않는다.
- 히어로의 주 화면은 실제 앱의 근력 운동 예시 미션/진행현황/날짜별 기록이다. 앞쪽 루틴 활동도 실제 앱 캡처다. 브라우저 perspective·작은 기울기·그림자로 깊이를 주며 숫자나 컨트롤을 새로 그리지 않는다.
- 미션/루틴/기록 기능 소개에도 실제 설정·활동·진행현황 캡처를 사용한다. 한국어 예시라는 안내를7언어로 유지한다. 임의 스마트폰 UI나 가짜 센서 데이터를 실제 화면이라고 표시하지 않는다.
- 자동 회전·스크롤에 따른 강제 움직임은 추가하지 않았다. 제한된 hover 효과는 reduced-motion에서도 불필요한 움직임을 줄인다.

## 앱 식별과 중복 버튼

- 앱 adaptive launcher가 실제 참조하는 `doti_doit_launcher_icon_source_v2.png`를 확인해 홈페이지용192px 아이콘과96px favicon을 만들었다. 글자형 로고와 구별해 히어로·하단 설치 CTA·브라우저 아이콘에 사용한다.
- 히어로 ‘첫 미션 시작하기 →’는 배경/테두리 없는 글자 링크로 바꿨다. 키보드 초점과 충분한 클릭 높이는 유지한다.
- 상단의 별도 ‘앱 설치하기’ 버튼과 모바일 상단 메뉴 안 설치 링크를 제거했다. 히어로와 하단의 Google Play 배지, 기존 푸터 동선은 유지한다.
- 설치 링크가 Google Play 상세로 바로 가는 기존 동작과7언어의 스토어 언어 설정을 유지한다. 기존 `/download/` 주소는 간결한 호환 안내다.

## 앱 저장소와 분리

사용자의 별도 요청으로 두 앱의 최근 수정8개는 문서화 후 소스만 선별 원복했다. 앱 저장소의 `docs/handoffs/2026-11-27-app-changes-rework-handoff.md`가 기준이다. 이 홈페이지 작업은 앱 코드·공개 APK·패키지·서명·서버 API/DB를 변경하지 않는다. 앱 소스를 원복했다고 홈페이지의 공개 모티도티 로고까지 자동으로 덮어쓰지 않는다.

## 캡처 여백·완성된 편집 예시 후속 보완

- 사용자가 캡처 내부가 가장자리에 붙어 답답하다고 지적해 모든 기능 발췌 이미지에 원본 기준 사방64px의 흰 여백을 추가했다. 앱 컨트롤·글자 자체를 늘이거나 지우지 않았다. 입체 패널에도 PC14px/모바일10px 안쪽 여백을 주었다. 장식용 보더나 이중 배경은 되살리지 않는다.
- ‘이미지 편집에서 함께 꾸미기’는 도구막대만 보여주던 구성을 없애고, **공식 근력운동 미션의 실제 피드 배경 + 운동30분 + 세 가지 루틴 실적 + 메모·스티커**를 꾸민 완성 예시와 실제 도구막대를 함께 보여준다.
- 완성 카드는 웹에서 만든 예시 일러스트다. 실제 앱 캡처로 오인하지 않도록 ‘기록 카드 꾸미기 예시 · 한국어’를7언어로 표시한다. 기록 수치는 예시이며 실제 사용자의 실적을 가져오지 않는다. 앱 테마 이미지는 원본 그대로 사용한다. 도구막대는 실제 앱 캡처다.
- 재생성은 `node scripts/build-record-card-example.mjs` 및 `python3 scripts/crop-guide-screenshots.py`. 배경 출처·해시·예시값은 [예시 출처](qa/2026-11-27-guide-simplification/record-card-provenance.json)에 남긴다.
- 변경 후 안내49조합과 홈35조합 브라우저 검사를 다시 실행해2개 모두 통과했다. PC/모바일에서 [완성 예시](qa/2026-11-27-guide-simplification/editor-example-1440.png), [모바일 예시](qa/2026-11-27-guide-simplification/editor-example-390.png), [여백 변경](qa/2026-11-27-guide-simplification/roomy-mission-1440.png)을 직접 확인했다.
