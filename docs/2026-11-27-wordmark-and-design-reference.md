## 적용 범위와 판단

사용자 제공 redow 레퍼런스의 제품 중심 입체 연출·재질·빛·절제된 편집 구성을 참고했다. 레퍼런스의 주황색을 그대로 적용하거나 앱 색만 쓰는 제한으로 해석하지 않았다. 모티두잇의 네이비/오렌지에 아이보리·소프트 그레이를 보조색으로 사용했다. 로고·실제 앱 UI를 다른 회사 것으로 바꾸지 않았다.

- 히어로: Android 펀치홀 형태의 기기, 활동 리포트, 반투명 경로 타일과 세라믹/유리 재질의 원본 3D 이미지로 교체했다. 히어로의 리포트는 기능 소개용 일러스트다. 실제 앱 화면으로 표시하지 않는다.
- 기능 3개: 미션·루틴·기록 각각에 별도의 원본 입체 이미지를 만들고 기능별 색/형상과 여백을 조합했다. 같은 상자를 반복하는 구성을 없앴다.
- 사용 안내, FAQ, 설치 CTA와 모티도티 소개, 내비게이션·푸터·상세 안내 페이지도 같은 톤으로 정리했다. 모바일 첫 화면에서 설치 동선이 밀리지 않게 소개문을 짧게 표시한다.
- 메인 아트 WebP 4종 합계는 약 220KB다. 외부 폰트·새 추적 SDK·애니메이션 라이브러리를 넣지 않았다. 기존 방문 통계 동의와 거부·철회 흐름을 유지한다.
