# Play 재심사 전 안내·7개 언어 점검

2026-11-06 KST. 앱 기준은401(1.0.244), 이전 Play391 이후의 변경을 반영했다. 새 AAB 제작·Play Console 제출은 하지 않는다.

## 홈페이지 변경

한국어·영어·일본어·중국어 간체/번체·스페인어·베트남어의 기록/피드, 루틴, 미션, FAQ, 운동 루틴 안내, 동영상 안내를 수정했다. 기존84페이지와 주소·디자인은 유지한다.

- 사진/영상/직접 만든 카드 중 최소 하나를 첨부하고, 미션·수행 일시→소감→기록 선택으로 작성한다.
- 직접기록 본문 필수 포함과 없음 표시, 혼합 기록 그룹을 구분한다. 이미지 위 오버레이 선택은 독립적이다.
- 부모 이름 개별 선택, 부모별 활동 중복 정리, 수행 날짜/시각 중복 제거, 히스토리 그래프/트리 아이콘을 안내한다.
- 측정/루틴 탭, 횟수 버튼, 루틴 없는 경과 시간과 완료된 루틴의 계속 수행 비활성화를 안내한다.
- 리포트형 배경,4개 디자인, 전체/개별 및 항목명·수치·단위별 서식을 반영했다. 과거의 ‘항상 같은 글자 서식’ 설명은 제거했다.
- 디자인 이름과 혼합 기록 그룹은 앱의 실제 번역과 일치시켰다. 언어 메뉴의 접근성 이름도 현재 언어로 제공한다.
- MP4 선택 구간 공유와 ZIP의 원본 전체 포함 안내를 유지한다. 새 원고에서 빠졌던 기록 페이지의 MP4 설명을 기존 회귀 검사에서 발견해7개 언어 모두 복원했다.

## 검사

기존 및 신규 Playwright 고유13개를 통과했다. 콘텐츠 보완 후 전체84페이지 320px·언어 전환·새 기능/개인정보 링크·영상 안내를 포함한5개를 재검사했다. 공개 빌드와 내부 링크/메타데이터 검사를 통과했다. 앱 언어 변경은 사용자 작성 원문을 자동 번역하지 않는다.

개인정보처리방침은 기존 데이터 처리 범위를 유지하며,7개 언어 본문과 앱 런타임 출력이 일치한다. 개인정보 페이지 언어 메뉴 접근성 이름만 현지화했으며 본문·시행일은 바꾸지 않았다.

공개 배포와 HTTP 전체 대조 결과는 후속 검증 파일에 기록한다.
