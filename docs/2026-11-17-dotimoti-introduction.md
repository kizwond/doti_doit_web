# 도티모티 홈페이지 소개 추가 (2026-11-17)

사용자 요청: 기존 도티두잇 설명 홈페이지에 도티모티를 함께 설명하는 영역 추가. 이어서 앱 문의를 모아 담당자가 답변하는 관리자 화면의 가능성을 질문했다.

## 적용

- 홈 기록 영역 다음에 도티모티 소개를 배치했다. 기존 남색·주황색 계열과 밝은 청색 배경을 사용하며 실제 새 모티 두 새싹 자산을 가져왔다. 구형 녹색 워드마크로 공통 UI 방향을 바꾸지 않았다.
- 미션·루틴·개인 기록 → 사용자가 선택한 SNS 게시 → 응원·공유 미션 시작 흐름을 예시로 설명한다. 예시는 실제 사용자 게시물/성과가 아니라는 문구를 표시한다.
- `/dotimoti/` 상세 페이지와 상단/하단 메뉴 연결,7언어 번역을 추가했다. 총13개 원고/목록 화면 ×7언어 =91페이지. canonical/언어 대안/사이트맵/프로젝트 경로는 기존 빌더를 재사용한다.
- 앱의 개인 기록과 SNS 게시 구분, 승인된 응원자, 나도 시작, 계정 공개범위, SNS 휴식 및 캠페인 예외를 설명한다. 개발 중임을 명시하며 설치 주소를 꾸미거나 회사 프리뷰 APK를 노출하지 않는다. 두잇과 모티의 계정/기록이 자동 연결되는 것으로 표현하지 않는다.
- 도티모티 페이지 하단은 두잇 둘러보기로 연결하고 도티두잇 설치를 모티 설치처럼 표시하지 않는다. 공통 하단 개인정보 링크도 도티두잇용임을 명시했다.

## 근거

새 모티 Preview49 README, `docs/MOTI_SOCIAL_CONTRACT.md`, `docs/handoffs/2026-11-16-sns-rest-publish.md`, `docs/handoffs/2026-11-17-settings-pruned.md`, `MotiSnsRestSettings.kt`, `MotiPostComposer.kt`와 현재 SNS 구성. 앱/백엔드/DB/권한/Shared 코드는 변경하지 않았다.

## 검증

미리보기91페이지 제목·메타데이터·내부 링크/이미지·목차 검사 통과. 브라우저 고유15개 검사 통과(기존3개 결과 재사용, 변경 대상12개 최종 재검사).91페이지/7언어/320px 넘침·이미지, JS 없는 메뉴/언어 전환, 도티모티 현재 메뉴와 상세 이동/개발 중 표시, 320·390·768·1024·1280·1440px 레이아웃, 초안 제외 및 GitHub 프로젝트 경로/404/기존 안내 회귀를 포함한다. 긴 홈의 지연 로딩 이미지는 각 이미지를 실제 스크롤해 검사하도록 보완했다. 데스크톱/모바일 새 영역 캡처를 직접 확인했다.

검사 로그는 작업 기기 `~/.local/state/doti-web-moti-*-20261117.log`, 캡처는 Git 제외 `test-results/dotimoti/`에 있다. 공개 빌드·배포 결과는 완료 후 추가한다.

## 문의 관리 검토

기존 서버에 문의 모델/접수·내역·답변·상태 변경·관리자 권한 API가 있으며 공개 스키마에서 존재와 비로그인 관리자 권한 false를 확인했다. 실제 문의 내용은 열람하지 않았다. 새 모티 문의하기는 미연결 상태다. 관리 기능을 구현했다는 안내나 작동하지 않는 관리자 메뉴를 홈페이지에 넣지 않았다. [검토안](2026-11-17-support-console-plan.md)은 담당자 로그인/앱 접수/답변 확인/API 권한 검사로 구성한다.
