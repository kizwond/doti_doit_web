# 공식미션 명칭 통일

2026-11-23. 공개 미션 소개·FAQ·기록 소개·영상 가이드·도티모티 소개의 ‘공인미션’을 ‘공식미션’으로 변경했다. 동작·외부 URL·7언어 페이지 구성을 유지한다. 과거 배포 기록은 보존했다.

프로덕션 빌드의 HTML/내부 링크/언어 검사를 실행하고 한국어 공개 페이지에 이전 용어가 다시 포함되지 않는 검사를 추가했다. main 푸시 후 기존 GitHub Pages 워크플로로 배포하며 실제 공개 페이지도 확인한다. 앱/개인정보처리방침의 동시 정리 인계는 도티두잇 `docs/handoffs/2026-11-23-official-wording.md`에 모은다.
