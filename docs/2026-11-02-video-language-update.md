# 동영상 기능과 7개 언어 안내 정비

기준 앱은 광고 OFF Preview 1.0.216(373)이다. 기존 Play 설치본에는 동영상 기능이 없을 수 있어
가이드에 지원 버전 안내를 둔다. 새 Play AAB와 스토어 심사 제출은 이번 작업 범위가 아니다.

영상 가져오기·512MB 제한·구간 선택·전체보기/채우기·배치·기록 오버레이·기본 음소거
자동 반복 재생·화면 터치 일시정지·사진 핀치 확대·공유 MP4를 설명했다.
피드 재생 스피커와 공유 MP4 음소거는 별개이고 ZIP에는 잘라낸 구간도 포함한 원본 전체가
들어간다. 회사 서버 업로드나 자동 공개 기능으로 설명하지 않는다.

`/guides/video-feed/`를 7개 언어로 추가했다. 기록·FAQ·홈도 갱신하며 서버형 루틴 링크
가져오기 지원이 끝난 점을 바로잡았다. 총 12개 화면 × 7개 언어 = 84개 페이지다.
하단 개인정보처리방침은 읽는 언어의 공개 방침으로 연결한다.

## 확인과 공개

`npm run build:preview`, `npm run check`, `npm test`로 문구·메뉴·페이지·320px 화면·
언어별 영상 가이드·개인정보 링크를 검사한다. 공개 빌드는 아래 명령이다.

```
SITE_URL=https://kizwond.github.io/doti_doit_web npm run build
```

앱 7개 언어 검사 통과 후 `main`에 푸시한다. GitHub Actions의 Pages 빌드/배포와 실제
공개 HTTP 본문까지 확인한 결과는 `docs/qa/2026-11-02-video/`에 남긴다.
생성된 `dist/`, 전체 길이 브라우저 캡처 `artifacts/`는 추적하지 않는다.
공개 방침 저장소의 기존 `.worktrees/`는 사용자 작업이므로 변경하지 않는다.
