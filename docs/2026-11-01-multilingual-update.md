각 언어는 기존 11개 화면 전체(홈·이야기·미션·루틴·기록·FAQ·설치·가이드 목록·세부 가이드 3개)를 제공해 총 77개다. 상단 언어 선택은 읽던 글의 같은 언어별 주소로 이동한다. 메뉴·접기·언어 링크는 JavaScript 없이 동작한다. 자동 기기언어 이동이나 방문자 추적·번역 API는 추가하지 않는다. 웹 언어 선택은 URL로 유지되며 앱 언어 설정과 별개다.

## 반영한 기능

- 과거 스마트폰 미사용 시간 설명을 현재 마지막 휴대폰 사용 종료 항목으로 정정. 상시 측정 지원 조건과 동의·권한·기기/데이터 제공처 조건 안내.
- 성공 기준의 기간·측정변수·최소/최대·값·단위와 필수 항목 잠금, 기존/수집 중 기록 재판정.
- 당일 00시부터 제공처에 존재하는 걸음수를 표시·판정에 포함. 운동 중 걸음수와 하루 누적의 중복 합산 방지.
- 위치 권한과 GPS 수신 구분, 권한 누락 시 수행 화면 안내.
- 사진 중심 피드와 필요한 기록 직접 선택, 기록카드 자동 삽입 없음. 제목·값 인라인/같은 서식, 전체 글자의 크기·색상·폰트·굵게·기울임, 개별 편집·실행 취소.
- 새 도티 이미지 기본 어둡기 50%와 기존 이미지/사용자 조정 보존.
- 언어 7개와 기기 언어 따르기, 선택 저장과 사용자 이름/메모 보존.
- 루틴의 예정 시간과 실제 기록 구분, 임시저장 완료 후 변경 안내.

스토어 설치본마다 동일 기능이 모두 배포되었다고 보장하지 않는다. 설치 안내에서 버전·기기별 차이를 설명한다. Play 설치 링크는 기존 검색 방식이며 회사 Preview APK를 일반 설치 링크로 노출하지 않는다. 홈페이지 화면 예시는 계속 설명용 일러스트/기록 예시로 표시하고 실제 캡처라고 하지 않는다. 번역 원고는 수동 작성한 안내이며 원어민 전수 감수를 의미하지 않는다.

## 유지 관리

한국어 본문은 `content/pages/`·`content/guides/`, 다른 언어의 글·제목·설명은 `content/i18n/<code>.json`, 공통 홈/메뉴/접근성 문구는 `content/i18n/chrome.tsv`다. TSV 열은 한국어·영어·일본어·간체·번체·스페인어·베트남어 순이다. 번역 키가 빠지면 빌드가 실패한다. 언어별 canonical·hreflang 7종/x-default와 77개 사이트맵을 생성한다. 새 페이지를 공개하려면 모든 언어의 원고도 준비한다.

한국어 루트는 유지해 기존 링크가 깨지지 않는다. 언어 선택은 각 페이지에서 다른 언어의 동일 문서로 이동한다. 개인정보처리방침은 기존 공식 한국어 문서에 연결하며 번역된 법적 문서가 있다고 표시하지 않는다.

## ローカル検証 / 로컬 검사

`npm ci`(취약점 0)·`npm run build:preview`·`npm run check`·`npm test` 10개 통과. 기존 검사 7개에 77개 전 페이지의 320px 레이아웃·언어·본문 번역·이미지, JavaScript 없이 7개 언어로 같은 문서 전환, 언어별 390/1440px 화면 캡처를 추가했다. 첫 검사에서 스페인어/베트남어 홈 제목의 기존 nowrap을 발견해 언어별 자연스러운 줄바꿈과 그리드 축소를 적용한 뒤 통과했다. 간체와 번체에 동일한 제목이 있을 수 있어 제목 중복은 언어 내부에서 검사한다. Playwright 공개 프로젝트 경로 검사도 통과했다.

CUA에는 연결된 브라우저가 없어 사이트를 채팅 옆에 직접 열지 못했다. 저장소의 Playwright/Chromium으로 실제 브라우저 자동 검사와 스크린샷을 수행했다. 일본어·스페인어·베트남어의 대표 화면을 육안 검토한다. 모든 번역을 원어민이 전수 감수한 것은 아니다.
